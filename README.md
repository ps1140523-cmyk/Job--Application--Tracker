# Job Application Tracker
A Web application built using Python and Flask to help job seekers manage and track job applications in one place.
## Features
- Add new job applications
- Track applications status 
- Manage interview details
- Store applicaion records
- Organize job search progress
## How to Run the Project
1. Clone or download this repository.
2. Open the project folder in VS code.
3. Install the required dependencies:
pip install -r requirements.txt

4. Run the application:

python app.py

5. Open yor browser and visit:

http://127.0.0.1:5000

## Project Purpose 
This project helps job seekers organize their applications and track their job search progress in one place.
